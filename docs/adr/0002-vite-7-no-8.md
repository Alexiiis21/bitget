# ADR 0002 — Vite 7, no Vite 8

- **Estado:** aceptada
- **Fecha:** 27 de julio de 2026
- **Fase:** 1

## Contexto

El entregable 1 declaraba «electron-vite 5 + Vite 8». Al instalar por primera vez, el
árbol de dependencias no resuelve:

```
npm error Could not resolve dependency:
npm error peer vite@"^5.0.0 || ^6.0.0 || ^7.0.0" from electron-vite@5.0.0
```

`electron-vite@5.0.0` —la última publicada— no soporta Vite 8. Y `@vitejs/plugin-react@6`
exige Vite 8. Las dos restricciones son incompatibles entre sí.

## Decisión

- `vite@^7.3.6`
- `@vitejs/plugin-react@^5.2.0` (la última que acepta Vite 7)
- `electron-vite@^5.0.0` sin cambios

## Razones

`electron-vite` es la columna del proyecto: orquesta los tres bundles (principal, preload
y renderer), aplica `externalizeDepsPlugin` y gestiona el arranque en desarrollo.
Sustituirlo por una configuración manual de Vite para Electron es trabajo real y frágil, a
cambio de una versión mayor de Vite que no aporta nada a este producto.

Vite 7 es una versión estable y mantenida. La diferencia con Vite 8 no es observable en un
proyecto de este tamaño.

## Consecuencias

- Verificado: `npm run build` compila los tres bundles.
- `@vitejs/plugin-react` queda una versión mayor por detrás. Sin impacto funcional.

## Reversión

Al publicarse `electron-vite@6` con soporte de Vite 8, subir las tres piezas a la vez:
`vite@8`, `@vitejs/plugin-react@6`, `electron-vite@6`. La anotación está en
`package.json` → `comments.vite`.
